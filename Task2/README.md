# Блэкджек

Учебный проект для второй аттестации.
Java 21, Maven, JUnit 5.

## Сборка и тесты

```bash
mvn clean verify
```

## Запуск

```bash
java -cp target/Task2-1.0-SNAPSHOT.jar org.example.blackjack.console.BlackjackApplication
```

Для воспроизводимого запуска укажите зерно:

```bash
java -cp target/Task2-1.0-SNAPSHOT.jar org.example.blackjack.console.BlackjackApplication 42
```

Без аргумента зерно выбирается автоматически и выводится в консоль.
Повторение партии требует одинаковых зерна и действий игроков.

## Управление

1 — взять карту.
2 — остановиться.
3 — удвоить ставку.
4 — разделить пару.
5 — сдаться.

При предложении страховки вводится сумма; 0 означает отказ.
После раздачи 1 запускает следующую раздачу.

## Правила стола

- Башмак состоит из шести колод.
- В консольном приложении начальный баланс каждого игрока — 100,
  основная ставка — 10.
- Балансы сохраняются между раздачами.
- Дилер добирает до 17 и останавливается на мягких 17.
- Обычный выигрыш оплачивается 1:1, начальный блэкджек — 3:2.
- При ничьей ставка возвращается.
- Удвоение разрешено на первых двух картах и завершает руку
  после получения одной дополнительной карты.
- Разделять можно карты одинакового достоинства.
- Максимум четыре руки у игрока.
- После разделения тузов каждая рука получает одну карту
  и останавливается.
- 21 после разделения не считается начальным блэкджеком.
- Удвоение после разделения разрешено для активной руки.
- Сдаться можно с исходной рукой из двух карт;
  возвращается половина ставки.
- Страховка предлагается при открытом тузе дилера.
  Максимальная сумма — половина основной ставки.
  Выигрыш по страховке оплачивается 2:1.
- Башмак обновляется между раздачами, когда оставшихся карт
  недостаточно для консервативного запаса на все возможные руки.

## Модель

- Card, Rank, Suit — карты, достоинства и масти.
- Hand и HandEvaluator — набор карт и расчет очков.
- Money и Player — денежные суммы и игроки.
- Shoe — создание, перемешивание и выдача карт.
- RoundHand — рука со ставкой и состоянием.
- BlackjackRound — фазы, очередность действий и расчет результатов.
- GameEvent и его реализации — события раздачи.
- HandView — неизменяемый снимок руки для вывода.

Механика не печатает в консоль.
Вывод и ввод находятся в пакете console.

## Примененные решения

GameAction и его наследники реализуют паттерн «Команда»:
приложение создает действие и выполняет его через общий метод execute.

Перечисление HandOutcome рассчитывает выплаты.
Для коллекций применяются обобщенные типы.
Итоговые балансы сортируются компаратором с лямбдами.
Значения Card, Money и PlayerId представлены неизменяемыми record.
