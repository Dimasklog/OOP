# Маршруты городского транспорта

## Модель предметной области

Модель построена по принципу композиции и описывает транспортную сеть города.

### Основные сущности

- **`TransportStop`** (record) — остановка транспорта. Идентификатор (код) и имя. Реализует корректную пару `equals`/`hashCode`.
- **`Segment`** (record) — участок маршрута между двумя остановками с временем хода.
- **`Trip`** (record) — рейс по маршруту. Хранит код маршрута, время отправления и признак дня.
- **`Route`** — маршрут как упорядоченная последовательность остановок со временем хода между ними и набором рейсов.
- **`TransportNetwork`** — транспортная сеть, агрегирующая маршруты и предоставляющая операции поиска.

### Иерархия поездок

Интерфейс **`Journey`** объявлен как `sealed interface`, что закрывает иерархию двумя реализациями:

- **`DirectRoute`** (record) — прямая поездка без пересадок.
- **`TransferRoute`** (record) — поездка с одной пересадкой, состоит из двух плеч (`DirectRoute`).

Полиморфные методы интерфейса: `allTimeInJourney()`, `countTransfer()`, `feasibility()`.

### Вспомогательные записи

- **`ScheduleEntry`** (record) — запись расписания (маршрут, рейс, время прибытия).

### Перечисления

- **`TransportType`** — типы транспорта с полями «скорость» и «вместимость»: `BUS`, `TRAM`, `TROLLEY`, `METRO`.
- **`DayType`** — признак дня: `WEEKDAY` (будний), `DAYOFF` (выходной).

### Исключения

Собственные исключения, расширяющие `RuntimeException`:

| Исключение | Смысл |
|---|---|
| `FeasibilityJourneyException` | Запрос времени у неосуществимой поездки с пересадкой |
| `ForeignTripException` | Рейс не принадлежит маршруту |
| `DuplicateTripException` | Дубликат рейса в маршруте |
| `LessTripException` | Рейсов указанного дня меньше двух |
| `RangeIndexException` | Индекс остановки вне диапазона |
| `TransportStopNotInRouteException` | Остановка не входит в маршрут |

## Операции

### Базовый уровень

1. **Расписание рейсов по остановке** — `TransportNetwork.timetable(stop, dayType)`. Возвращает отсортированный по времени прибытия список записей расписания для указанного признака дня.
2. **Расчётное время прибытия на k-ю остановку** — `Route.arrivalKStop(trip, k)` и `Route.arrivalNameStop(trip, stop)`.
3. **Интервал движения на маршруте** — `Route.intervals(dayType)`. Возвращает список интервалов между соседними отправлениями.
4. **Маршруты без пересадки между двумя остановками** — `TransportNetwork.directRoutesBetween(first, second)`.
5. **Общее время в пути** — `Journey.allTimeInJourney()`.

### Повышенный уровень

1. **Поездка с одной пересадкой** — класс `TransferRoute` проверяет, что на пересадку хватает времени (норматив — 1 минута, константа `Journey.timeTransfer`).
2. **Выбор варианта с наименьшим общим временем** — `TransportNetwork.transferRouteWithMinTime(from, to, dayType)`. Возвращает `Optional<TransferRoute>`.
3. **Отдельное расписание выходного дня** — все методы расписания принимают параметр `DayType`.
